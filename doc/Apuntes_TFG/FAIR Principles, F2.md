# Data are described with rich metadata:
While principle [[FAIR Principles, F1|F1]] enables unambiguous identification, principle F2 speaks of the ability to discover a resource of interest. Is generally hard to define the minimally required richness of this metadata but the more generous it is the more specifically findable it becomes in refined searches.
