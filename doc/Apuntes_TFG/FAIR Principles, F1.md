# (Meta)Data are assigned a globally unique and persistent identifier:
In order to be found and resolved by computers data and metadata must be assigned a unique identifier that is guaranteed to unambiguously refer to exactly one resource in the world. And for it to be persistent it requires to not be reused in another context.

## Implementation considerations:
The greatest challenge is to ensure the longevity of the identifiers. In particular that identifiers created by a project should survive the termination of said project.
A common example of a useful identifier is the Digital Object Identifier ([[DOI]]). DOIs provide an additional service under principle [[FAIR Principles, A1|A1]], of being able to direct calls to the source data to the location of that data, even if the identified data moves.
