# Principios FAIR:
Los principios FAIR pretenden mejorar la publicación de datos científicos para un mejor entendimiento para tanto humanos como máquinas. No son un estándar ni promueven una tecnología concreta, son principios guía que no se cumplen de manera binaria, un sistema siempre puede ser "más FAIR".
>(Aranguren, 2022/2024)

FAIR significa:
- **F**indable.
- **A**ccesible.
- **I**nteroperable.
- **R**eusable.
El 80% del tiempo invertido a la investigación se dedica a buscar, filtrar e integrar datos.
>(Press, s. f.)

Además la reproducibilidad de un experimento es crucial en ciencia, y a día de hoy existe una crisis de reproducibilidad debido a datos no publicados o publicados de manera inadecuada, lo cual deja patente la necesidad de la implementación de los principios FAIR.

# Findable:
Data should be identified using globally unique, resolvable, and persistent identifiers, and should include machine-actionable contextual information that can be indexed to support human machine discovery of that data.
